# Test Task

This repository contains a simple Python task and its corresponding unit tests.

## Running the Task

To run the task script, use the following command:

```bash
python3 task.py
```

## Running the Tests

To run the unit tests, use the following command:

```bash
python3 -m unittest test_task.py
```

Make sure you have Python 3 installed and accessible via the `python3` command.
